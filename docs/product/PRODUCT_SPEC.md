## 제품 정의와 흐름

PawBloom는 **내 반려동물을 닮은 캐릭터들이 함께 지내는 공간에서 실제 돌봄과 가족의 추억을 쌓는 앱**이다.
초기 대상은 사진을 자주 찍고 가족·연인과 돌봄을 나누는 보호자다.
케어가 잦은 보호자는 전체 일정으로 바로 접근한다.

1. 기존 아이를 선택하거나 새 아이를 등록하고 사진을 촬영하거나 앨범에서 고른다.
2. 사진 기반 캐릭터를 생성하고 결과를 확인한 뒤 우리 집에 배치한다.
3. 여러 아이를 함께 보고 위치를 옮기거나 아이를 눌러 상세로 들어간다.
4. 식사·물·산책·배변·컨디션·투약을 실제 아이 기준으로 기록한다.
5. 가족이 사진과 이야기를 남기고 함께 나온 아이들을 한 추억에 연결한다.
6. 아이별 기록 브리핑을 검토하고 병원용 리포트를 확인·공유한다.

캐릭터는 기록으로 들어가는 입구다. 재생성·교체·이동은 기존 petId와 케어·추억을 바꾸지 않는다.

## 유지하는 기능과 데이터

- 계정·프로필·다중 반려동물, 기존 역할·계정 삭제·가족 공동 기록.
- 강아지·고양이 케어 템플릿, 기타 동물의 기본 프로필·기록.
- 식사·물·선택형 산책·배변·컨디션·메모·사진과 날짜별 조회·편집.
- 구조화 기록의 날짜·아이·카테고리별 갱신, 사진·메모의 하루 복수 기록 규칙.
- 루틴 기본값, 여러 상태·약, 용량·시작/종료일·복용 시간·반복 간격.
- 예정 투약·완료·건너뜀·부분 복용·일시 투약. 예정만으로 실제 dose를 만들지 않는다.
- 식사·투약 기기 로컬 알림, 비공개 사진, 오프라인 케어 저장·재전송·충돌 안내.
- 기록 요약·누락 기록·수의사 질문과 확인 후 만료형 sanitized 병원 리포트 공유.
- 현재 브리핑은 템플릿 요약이다. LLM 브리핑·AI 진단을 이미 제공한다고 설명하지 않는다.

## 화면 구성

하단 메뉴는 **우리 집 / 오늘 케어 / 추억 / 더보기** 네 개다.

| 화면 | 주요 내용 |
| --- | --- |
| 우리 집 | 열람 가능한 여러 아이 캐릭터, 아이 추가·기록 추가, 가까운 일정·미확인 케어 요약 |
| 오늘 케어 | 접근 가능한 모든 아이의 오늘 루틴·투약, 시간순 목록, 아이 필터·빠른 기록 |
| 추억 | 사진·이야기·작성자·날짜·함께한 아이, 전체 목록·아이별 필터 |
| 더보기 | 아이 관리·가족 초대·알림·언어·계정·지원·기존 플랜 상태 |

아이를 누르면 이름·실제 사진·오늘 케어·최근 추억과 빠른 기록이 있는 요약창을 연다.
상세는 **케어 / 추억 / 프로필**이다. 케어 안에 브리핑·병원에 전달하기를 둔다.
기존 Diary·Care·Reports 로직을 연결한다. 입력·저장·알림 진입에 대상 이름과 사진을 표시한다.

## 사진 기반 캐릭터

- 기존/신규 아이 모두 촬영·앨범 선택 → 생성 → 확인 → 적용을 지원한다.
- 첫 버전은 강아지·고양이의 통일된 2D 스타일 한 가지다. 기타 동물은 사진/기본 캐릭터로 참여한다.
- 털 색·얼굴 무늬·귀 모양 등 닮은 특징과 움직임 중 외형 일관성을 우선한다.
- 생성 중·실패·재시도·사진 교체를 지원한다. 새 결과 적용 전까지 기존 캐릭터를 유지한다.
- 원본 사진은 유지한다. 생성 실패·오프라인에도 기본 캐릭터와 기존 기록 기능을 쓴다.
- 생성 서비스·비용·시간·보관/학습 조건은 선행 검증에서 결정한다. 미측정 품질·시간을 약속하지 않는다.

## 우리 집 공간

- 따뜻한 2D 공간 한 종류에서 여러 아이를 표시한다.
- 짧게 누르면 요약창, 길게 눌러 끌면 위치 이동이다. 이동 종료가 상세 열기로 이어지지 않는다.
- 눈 깜빡임·고개 돌림·앉기·짧은 배회를 제공하고 위치 고정·움직임 줄이기를 지원한다.
- 메뉴 뒤·화면 밖 이탈을 막고 겹친 아이는 목록으로도 선택한다.
- 아이가 많으면 공간을 좌우로 탐색한다. 터치 영역과 이름을 과도하게 축소하지 않는다.
- 배치는 계정·기기별 개인 설정이다. 가족의 위치를 실시간 공동 편집하지 않는다.
- 기록 후 짧게 반응하고 함께한 날·추억 수를 표시한다. 반응이 저장 성공을 대신하지 않는다.

## 공동 추억

- 사진·메모·날짜·작성자·함께한 아이를 저장한다. 사진 없이 이야기만 남기는 것도 허용한다.
- 같은 추억은 전체 목록에 한 번, 연결된 각 아이의 추억에 각각 표시한다.
- 복수 태그는 **동일한 활성 owner/caregiver 구성원 집합**의 아이들끼리만 허용한다.
- 저장 전 대상과 공개 범위를 표시하고 구성원 변경 시 서버가 재판정한다.
- 특정 아이 권한만 가진 사람에게 다른 아이의 이름·사진·내용을 노출하지 않는다.
- 식사량·투약·컨디션은 아이별 케어 기록이다. 공동 추억을 의료 요약 근거로 자동 포함하지 않는다.
- 기존 사진·메모는 계속 조회·편집한다. 새 추억 모델로 강제 복제하거나 기존 기록을 삭제하지 않는다.

## 가족·플랜·알림

- 기존 역할과 서버 인가를 유지한다. owner는 프로필·캐릭터·구성원을 관리한다.
- caregiver는 허용된 기록에 참여한다. pet_sitter의 오늘 기록 권한을 전체 추억 열람으로 넓히지 않는다.
- 복수 태그 추억의 생성/편집은 모든 대상에서 권한을 가진 owner/caregiver만 수행한다.
- Free/Plus/Family와 현재 제한을 문서 변경만으로 해제하지 않는다.
- 기본 가족 참여·다중 아이 체험 정책은 공개 베타 전에 확정한다. 새 결제·상점은 추가하지 않는다.
- [출시 전략](../engineering/RELEASE.md)의 무료 v1은 판매 방식 결정 전제인 권장안이다.
- 알림 탭은 인증·권한 확인 후 해당 아이·일정으로 이동하며 이동만으로 투약을 완료하지 않는다.

## 안전·저장 상태

- [AI 안전 정책](AI_SAFETY.md)을 유지한다. 캐릭터 감정은 연출이며 건강·감정 측정이 아니다.
- 기록 없음은 건강 악화·배고픔의 증거가 아니다. 기록을 안 했다고 아프게 하거나 사라지게 하지 않는다.
- 투약 완료·활동량 경쟁을 보상 조건으로 삼지 않는다. 건너뜀·부분 복용도 솔직하게 기록한다.
- 기존 케어 오프라인 저장을 유지한다. 새 사진 업로드·캐릭터 생성은 온라인 완료가 필요하다.
- 추억 입력·선택 사진은 계정별 전송 대기 초안으로 보존하고 공유 완료로 표시하지 않는다.
- 생성 실패·권한 거부·부분 업로드·동기화 충돌·구성원 변경·삭제의 복구 경로를 제공한다.

## 첫 버전 제외

3D, 미니게임, 재화·랭킹·교배, 상점·가구 꾸미기, 성격 챗봇, 실시간 공동 이동,
공개 커뮤니티, GPS, 보험·병원 예약, 신규 결제, 사진 의료 진단, 처방·용량 추천·응급 판단,
새 LLM 브리핑, 사진 백그라운드 자동 업로드 큐는 포함하지 않는다.

## 완료 기준

- 기존 아이 사진으로 캐릭터를 만들고 여러 아이를 이동·선택한다. 교체 후 기록이 유지된다.
- 아이별 기록이 섞이지 않고 전체 케어의 저장이 상세에도 반영된다.
- 가족 추억에 기여하고 복수 태그가 중복 업로드 없이 연결된다.
- 권한 변경·삭제·계정 전환 후 접근과 로컬 데이터가 정리된다.
- 알림에서 해당 아이로 진입하고 움직임을 꺼도 모든 기능을 쓴다.
- 자동 게이트와 iOS/Android 실행 검증을 각각 기록한다. 미구현·미검증을 완료로 표시하지 않는다.
